# PredictIA Industrial

MVP de mantenimiento predictivo IoT desarrollado para Práctica Profesionalizante II.

## Descripción

Sistema web orientado al monitoreo de una máquina inyectora de plástico mediante mediciones simuladas de temperatura y vibración.

## KIT Industria 4.0

AVZ-01 — Mantenimiento Predictivo IoT.

## Tecnologías aprobadas

- React
- Node.js
- Express
- MySQL
- API REST
- Git y GitHub

## Estructura

- `backend/`: API REST y lógica de la aplicación.
- `database/`: scripts de creación y carga de MySQL.
- `frontend/`: interfaz React.
- `docs/evidencias/`: evidencias técnicas del proyecto.
